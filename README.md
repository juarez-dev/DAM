Android Studio
El IDE oficial para el desarrollo de aplicaciones para android. Proporciona un conjunto completo de funcionalidades y herramientas que facilitan la creación, prueba y mantenimiento de la aplicación:
Editor de código inteligente basado en IntelliJ IDEA, un IDE desarrollado por JetBrains.
Soporte para Kotlin y java
Herramientas de depuración
Emuladores de dispositivos
Sistema de gestión de dependencias mediante Gradle
Potenciación mediante IA, integración con Gemini y/o Copilot
Además ofrce una integración directa con el SDK de Android, lo que garantiza compatibilidad con las versiones actuales del sistema operativo y buenas prácticas de desarrollo.

El uso de Android Studio asegura un desarrollo más organizado, seguro y profesional, optimizando el rendimiento y la experiencia del usuario final.


Kotlin 
Lenguaje de programación oficial de android recomendado por Google para el desarrollo android. Kotlin es un lenguaje de programación estático de código abierto que admite la programación funcional y orientada a objetos. Proporciona una sintaxis y conceptos similares a los de otros lenguajes, como C#, Java y Scala, entre muchos otros. No pretende ser único, sino que se inspira en décadas de desarrollo del lenguaje. Cuenta con variantes que se orientan a la JVM (Kotlin/JVM), JavaScript (Kotlin/JS) y el código nativo (Kotlin/Native)
https://developer.android.com/kotlin/overview?hl=es-419
